# 🪷 ลอยกระทงออนไลน์ 3D & ประกวดโหวตกระทง (Loy Krathong Festival 3D)

เว็บแอปพลิเคชัน 3D Interactive สำหรับเทศกาลลอยกระทงและการประกวดโหวตกระทงออนไลน์ รองรับการแสดงผลแบบ Responsive เต็มรูปแบบทั้งบนคอมพิวเตอร์ (PC), แท็บเล็ต (Tablet) และสมาร์ตโฟน (Smartphone)

---

## ✨ จุดเด่นและฟังก์ชันการทำงาน

- **ภาพ 3D เสมือนจริงด้วย Three.js**:
  - แม่น้ำจำลองพร้อมคลื่นน้ำประมวลผลบน GPU (GPU-Accelerated Water Shader) ลื่นไหล 60-120 FPS
  - ดวงจันทร์วันเพ็ญขนาดใหญ่ส่องแสงสีทองนวลสะท้อนผิวน้ำ พร้อมรัศมีเรืองรอง (Lunar Corona)
  - สถาปัตยกรรมไทย: เจดีย์ทองอร่าม, วัดไทยหลังคาซ้อนชั้นลดหลั่นพร้อมช่อฟ้า, และบ้านเรือนไทยยกใต้ถุนสูง
  - สะพานไม้ทรงไทยโค้งข้ามแม่น้ำ และสายไฟราวงานวัดประดับหลากสีริมตลิ่ง
  - ตัวละครผู้คน 26 คน สวมใส่ชุดไทยดั้งเดิม (สไบทอง, โจงกระเบน, ถือโคมประทีป)
- **ระบบกระทง 3D วิจิตร**:
  - ฐานหยวกกล้วยซ้อนชั้นพร้อมริบบิ้นใบตองสดพันขอบ
  - กลีบผกาและกลีบพับซ้อน 3 ชั้น ดอกดาวเรืองมงคล และพวงมาลัยดอกมะลิ
  - เทียนไขเปลวไฟกะพริบจริง และธูป 3 ดอกที่มีประกายไฟสีแดง
  - ป้ายชื่อ 3D ลอยเหนือกระทงแสดงชื่อผู้เข้าประกวด จังหวัด หมวดหมู่ และคะแนนโหวต
- **ระบบกล้องควบคุมอิสระ (Camera Orbit Controls)**:
  - หมุนรอบฉาก 360 องศา, ซูมเข้า-ออก (รองรับ Touch Pinch-to-zoom และ Drag บนมือถือ)
  - ระบบกล้องแบบโดรนภาพยนตร์ (Cinematic Drone Glide Lerp) เคลื่อนไหวสมูทนุ่มนวล
- **ระบบบันทึกข้อมูลและฐานข้อมูล Cloud Firestore**:
  - เชื่อมต่อ Google Cloud Firestore แบบ Real-time Sync
  - ถ่ายรูปเซลฟี่สดผ่านกล้อง หรือเลือกรูปจากอัลบั้ม
  - ระบบย่อขนาดรูปภาพอัตโนมัติไม่เกิน 500px (< 50ms) ก่อนบันทึกลง Firestore
- **โหมดเดี่ยวอัตโนมัติ (Auto Solo Focus Mode)**:
  - เมื่อผู้ใช้ปล่อยกระทง ระบบจะสลับเข้าสู่โหมดเดี่ยวแสดงเฉพาะกระทงของผู้ใช้ในแม่น้ำทันที เพื่อไม่ให้กระทงอื่นมาทำให้สับสน
- **ระบบโหวตและตารางอันดับ (Leaderboard)**:
  - แตะที่กระทงเพื่อเปิดดูข้อมูลเจ้าของ คำอธิษฐาน และกดโหวตพร้อมเอฟเฟกต์พลุ Confetti

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **3D Graphics Engine**: Three.js (r170)
- **Build Tool**: Vite 5
- **Database & Realtime**: Firebase / Cloud Firestore
- **Icons & Effects**: Lucide React, Canvas Confetti

---

## 🚀 วิธีการติดตั้งและรันโปรเจกต์

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้นรันเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev

# 3. สั่ง Build สำหรับ Production
npm run build
```
